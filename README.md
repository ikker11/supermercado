# Súper Barrio

Simulador de supermercado en primera persona para el navegador, sin anuncios. Empiezas con un local pequeño: pides género, repones a mano, abres de 8:00 a 22:00, cobras en la caja y vas creciendo hasta tener un supermercado con personal.

## Cómo se juega

1. **Ordenador** (mesa a la izquierda de la entrada): pide cajas de productos. Llegan a la zona amarilla.
2. **Reponer:** coge una caja con «Usar», mira una estantería y pulsa «Usar» para colocar cada producto. Mantén pulsado para ir más rápido. Las cajas vacías van a la papelera.
3. **Abrir:** toca el cartel rojo junto a la puerta. El reloj empieza a correr.
4. **Caja:** escanea cada producto del cliente y cobra en la caja registradora, con tarjeta o dando el cambio exacto en efectivo.
5. **Crecer:** al subir de nivel compras licencias de productos, más estanterías, amplías el local y contratas cajero y reponedores.
6. **Trucos:** en el menú (☰) tienes dinero, niveles, licencias, velocidad del tiempo, entrega instantánea, compras gratis y más.

Controles en el móvil: joystick a la izquierda para andar y arrastrar a la derecha para mirar. En el ordenador: WASD, ratón, clic o E para usar, Q para soltar y Mayús para correr.

## Partidas guardadas

La partida se guarda sola en el navegador de cada dispositivo. En **Menú → Copia de seguridad** puedes copiar un código con toda la partida y cargarlo después o en otro móvil.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `SUPERBARRIO`).
2. Sube estos archivos sueltos, sin carpetas: `index.html`, `game.js`, `style.css`, `manifest.json`, `icon-180.png`, `icon-192.png`, `icon-512.png`, `README.md`.
3. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`, y guarda.
4. Al cabo de un minuto el juego estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
5. En el iPhone, ábrelo en Safari y usa **Compartir → Añadir a pantalla de inicio** para jugar a pantalla completa.

Necesita conexión a internet para cargar la librería 3D (three.js).
